## Installation

1. Install the [Tampermonkey](https://www.tampermonkey.net/) extension for your browser. 
2. Open the Tampermonkey dashboard and create a new script.
3. Copy the entire JavaScript code of the **SLCM UI GACOR** script.
4. Paste it into the editor and save the file.

## Usage

1. Edit the `target_teks` array inside the script to configure your target courses. For example:

```javascript
// You can configure your target courses exactly as they appear on screen.

var target_teks = [
    "BREAKFAST 2026 (Kelas A)",
    
    "LUNCH 2026 (Kelas A)", 
    
    "DINNER 2026 (Kelas A)" 
];
```

2. Get the class name from the page "Jadwal" -> "Jadwal Kuliah"
3. Copy the class name ONLY from the blue-colored text (be careful not to make a mistake)
